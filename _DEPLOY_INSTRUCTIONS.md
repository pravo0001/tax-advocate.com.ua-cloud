# Как залить изменения на GitHub (шаг за шагом)

После того как Claude обновил файлы на вашем компьютере, нужно залить их обратно в репозиторий, чтобы они появились на сайте `taxlawyer.com.ua`.

## Самый простой способ (через веб-интерфейс GitHub)

### Шаг 1 — открыть репозиторий
1. Откройте: https://github.com/pravo0001/1
2. Войдите в свой GitHub-аккаунт, если ещё не вошли.

### Шаг 2 — загрузить изменённые файлы
1. На главной странице репозитория нажмите **`Add file`** (вверху справа, рядом с зелёной кнопкой "Code").
2. В выпадающем меню выберите **`Upload files`**.
3. Откроется страница загрузки. **Перетащите** в неё все файлы из вашей локальной папки `C:\Users\GLAZU\Downloads\1-main\1-main` (можно выделить все файлы Ctrl+A и перетащить мышкой). GitHub автоматически заменит существующие файлы.
4. Прокрутите вниз — там будет поле **`Commit changes`**.
5. В поле "Add an extended description" (или прямо в первом поле) напишите коммит: `Major UX/copy fixes: real cert, real cases, mobile bar, removed dev placeholders`
6. Убедитесь, что выбрано "Commit directly to the `main` branch".
7. Нажмите зелёную кнопку **`Commit changes`**.

### Шаг 3 — дождаться публикации (1–3 минуты)
1. После коммита GitHub Pages автоматически начнёт пересобирать сайт.
2. Откройте: https://github.com/pravo0001/1/actions — увидите статус деплоя (зелёная галочка = готово).
3. Через 1–3 минуты обновите `https://taxlawyer.com.ua/` — изменения будут видны.
4. Если кэш не обновляется — **Ctrl+F5** (жёсткая перезагрузка) или откройте сайт в инкогнито.

## Если что-то пошло не так

- **Сайт после публикации выглядит криво:** в Chrome нажмите Ctrl+F5 (жёсткая перезагрузка кэша).
- **Вместо обновлённых данных видите старые placeholder'ы:** убедитесь, что коммит прошёл (https://github.com/pravo0001/1/actions — должна быть зелёная галочка).
- **Какой-то файл сломался:** в репозитории GitHub откройте этот файл, нажмите кнопку "History" — там видна история коммитов, можно вернуться к любой предыдущей версии.
